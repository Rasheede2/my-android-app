# Abni Sami3 Novels — تشغيل بدون Android Studio

هذا المشروع يحتوي على مصدر تطبيق أندرويد. يمكنك بناء ملف APK من متصفحك عبر GitHub Actions دون تثبيت Android Studio أو Gradle على جهازك.

## خطوات بناء APK عبر GitHub

1. سجّل الدخول إلى GitHub وأنشئ مستودعاً جديداً (Repository). اختَر Private إذا أردت إبقاء الكود خاصاً.
2. فك ضغط هذا الملف على الكمبيوتر. ارفع **محتويات المجلد** إلى المستودع من زر **Add file → Upload files** ثم اضغط **Commit changes**. تأكد من رفع المجلد المخفي `.github` أيضاً؛ يحتوي على مسار `workflows/build-apk.yml`.
3. افتح تبويب **Actions** في المستودع. اختر سير العمل **Build APK** من القائمة، ثم اضغط **Run workflow**.
4. انتظر انتهاء البناء وظهور علامة النجاح الخضراء. افتح نتيجة التشغيل نفسها وانزل إلى **Artifacts**.
5. نزّل `AbniSami3Novels-debug-APK.zip`، وفك ضغطه لتحصل على `app-debug.apk`، ثم انقله إلى هاتف Android وافتحه للتثبيت. قد يطلب الهاتف السماح بالتثبيت من هذا المصدر. لا تسمح إلا إذا كنت تثق بالملف الذي بنيته.

## ما الذي سيتم بناؤه؟

- نسخة Debug قابلة للتثبيت للتجربة، وليست نسخة إصدار نهائي موقّعة للنشر على المتجر.
- واجهة رئيسية ولوحة أدوات، وزر يعرض أسماء الصور بعد منح الإذن، وزر يفتح تطبيق الكاميرا.
- هذه نسخة أولية وليست تطبيق روايات كاملاً؛ ملفات الروايات ونظام القراءة لم تكن موجودة في الأرشيف الأصلي.

## ملاحظات مهمة

- هذه الطريقة لا تتطلب Android Studio على جهازك، لكنها تتطلب حساب GitHub واتصال إنترنت لبناء المشروع على خوادم GitHub.
- لم يتم بناء APK داخل بيئة إنشاء هذا الأرشيف؛ البناء سيجري عند تشغيل سير العمل في GitHub Actions. إذا فشل، افتح سجل المهمة وانسخ رسالة الخطأ لمراجعتها.
- لم يُضمّن كود تسجيل كلمات المرور كنص صريح أو محاولة الوصول إلى رسائل واتساب الخاصة.
